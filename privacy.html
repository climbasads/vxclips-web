Política de privacidad de VxClips

Última actualización: 20 de octubre de 2026.

VxClips es una integración experimental para enviar clips de video a TikTok mediante autorización del titular de la cuenta.

Datos tratados

Si el usuario autoriza TikTok Login Kit, la integración podrá recibir identificadores básicos de la cuenta, credenciales OAuth de acceso y los videos que el usuario decida enviar. Solo se solicitarán los permisos necesarios para las funciones habilitadas.

Finalidad y almacenamiento

Estos datos se utilizarán para autenticar la cuenta y transferir contenido a TikTok. Los secretos de acceso se deberán almacenar en GitHub Actions Secrets; no deben incluirse en el código fuente ni en páginas públicas. Los archivos temporales podrán procesarse en GitHub Actions. No se venden datos personales.

Servicios externos

La integración utiliza GitHub Actions y la API de TikTok; estos proveedores procesan información de acuerdo con sus propias políticas.

Control del usuario

El usuario puede revocar la autorización desde TikTok y solicitar consultas o eliminación de datos mediante este canal de soporte. La revocación impide nuevas solicitudes autenticadas, sin afectar necesariamente publicaciones ya realizadas.
